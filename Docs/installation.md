# Installation Guide

## Linux Installation
1. Install `libpcap-dev`: `sudo apt-get install libpcap-dev`
2. Install Rust: `curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh`
3. Install Go: `sudo apt-get install golang-go`
4. Build: `make build`

## Windows Installation
1. Install Npcap (select "Install Npcap in WinPcap API-compatible Mode").
2. Install Rust via rustup.exe.
3. Install Go from the official installer.
4. Build: `make build`
